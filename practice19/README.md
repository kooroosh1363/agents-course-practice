# Practice 19: Cryptocurrency & Blockchain Agent

##  Description
This agent acts as a smart crypto portfolio and market assistant. It can:
- 💰 Calculate total fiat value of cryptocurrency holdings
- 📈 Calculate Return on Investment (ROI) percentage for trades
- 💸 Estimate trading fees based on volume and exchange rates
- 📊 Derive approximate coin price from market cap and circulating supply
- 🔍 Search the web for market news, tokenomics, and blockchain developments
