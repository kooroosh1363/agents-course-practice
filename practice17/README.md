# Practice 17: Sports & Game Stats Agent

## 📋 Description
This agent acts as a smart sports analyst assistant. It can:
-  Calculate player averages (points/goals per game)
- 📊 Calculate team win rates based on results
- 🏃♂️ Calculate running pace (minutes per kilometer)
- 📈 Project total season stats based on current performance
- 🔍 Search the web for latest standings, match results, and player news
