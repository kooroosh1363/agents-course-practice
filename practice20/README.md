# Practice 20: Meteorology & Weather Agent

## 📋 Description
This agent acts as a smart meteorological assistant for outdoor enthusiasts and environmental planners. It can:
- 🌬️ Calculate wind chill (perceived temperature)
- ️ Estimate rainwater harvesting volume from catchment areas
- ☀️ Calculate safe sun exposure time based on UV index & skin type
- 🏔️ Estimate altitude from atmospheric pressure readings
-  Search the web for weather forecasts, climate reports, and atmospheric science
