# Practice 12: Real Estate & Property Agent

## 📋 Description
This agent acts as a smart real estate assistant for buyers, investors, and renters. It can:
- 🏦 Calculate monthly mortgage payments (amortization formula)
- 📏 Compare properties using price per square meter
-  Estimate annual rental yield percentage for investments
- 💰 Validate rent affordability using the 30% income rule
- 🔍 Search the web for market trends, neighborhood guides, and investment tips
