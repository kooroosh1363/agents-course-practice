# Practice 22: Chemistry & Laboratory Agent

## 📋 Description
This agent acts as a smart laboratory assistant for chemists and researchers. It can:
- 🧪 Calculate molar concentration (Molarity) from moles & volume
-  Plan solution dilutions using C1V1 = C2V2 formula
- ️ Compute pH values from hydrogen ion concentration
- 🌡️ Convert temperatures between Celsius and Kelvin
- 🔍 Search the web for chemical properties, safety data sheets (SDS), and reaction mechanisms
