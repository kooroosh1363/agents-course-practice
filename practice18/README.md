# Practice 18: Gaming & Esports Agent

## 📋 Description
This agent acts as a smart assistant for gamers and esports enthusiasts. It can:
- 🎯 Calculate KDA ratios (Kills + Assists) / Deaths for MOBA/FPS games
- 📈 Track XP progress and calculate remaining XP to level up
- ⏱️ Format match duration from minutes to HH:MM time code
- ⚔️ Calculate Damage Per Second (DPS) for combat analysis
- 🔍 Search the web for patch notes, game guides, and esports tournament results
