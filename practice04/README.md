# Practice 04: Health & Fitness Agent

## 📋 Description
This agent acts as a health and fitness assistant. It can:
- ⚖️ Calculate Body Mass Index (BMI)
- 💧 Estimate daily water intake based on weight
- ❤️ Calculate estimated maximum heart rate
- 🔍 Search the web for health and fitness information
