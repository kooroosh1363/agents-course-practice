# Practice 05: Travel & Logistics Agent

## 📋 Description
This agent focuses on travel planning and logistics calculations. It can:
- 📏 Convert distances (kilometers to miles)
- ⛽ Calculate estimated fuel costs for road trips
- ⏱️ Estimate travel time based on distance and speed
- 🔍 Search the web for travel guides, routes, and tips
