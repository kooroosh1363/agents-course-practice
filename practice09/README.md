# Practice 09: E-commerce & Shopping Agent

## 📋 Description
This agent acts as a smart shopping assistant. It can:
- 🏷️ Calculate final prices after applying percentage discounts
- ⚖️ Compare prices by calculating price per unit (kg, liter, etc.)
- 📦 Estimate shipping costs based on package weight
- 🔍 Search the web for product reviews, deals, and comparisons
