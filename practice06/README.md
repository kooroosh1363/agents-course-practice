# Practice 06: Cooking & Nutrition Agent

## 📋 Description
This agent acts as a smart kitchen assistant. It can:
-  Scale recipe ingredients for different serving sizes
-  Convert volume measurements (cups to milliliters)
- 🔢 Calculate calories per serving
-  Search the web for recipes, cooking techniques, and nutrition facts
