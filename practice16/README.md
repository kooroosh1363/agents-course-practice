# Practice 16: Aviation & Flight Planning Agent

## 📋 Description
This agent acts as a smart assistant for pilots and aviation enthusiasts. It can:
- ⏱️ Calculate estimated flight time based on distance and cruise speed
- 🌬️ Convert ground speed from km/h to knots (nautical miles per hour)
- ⛽ Estimate total fuel required using burn rate and flight duration
- 🕰️ Calculate UTC arrival time from departure time and flight hours
- 🔍 Search the web for aviation regulations, weather METARs, and airport data
