# Practice 21: Network & IT Infrastructure Agent

## 📋 Description
This agent acts as a smart assistant for network engineers and sysadmins. It can:
- ️ Calculate estimated download times based on file size & bandwidth
- 🌐 Calculate usable host addresses in IPv4 subnets (CIDR /8 to /30)
- 🔄 Convert bandwidth units (Gbps to Mbps)
- 📦 Calculate packet transmission time over a network link
- 🔍 Search the web for RFC standards, protocol guides, and troubleshooting tips
