# Practice 11: Photography & Media Agent

## 📋 Description
This advanced agent acts as a smart assistant for photographers and content creators. It can:
- 📐 Calculate image resolution in megapixels
-  Estimate total storage required for photo/video shoots
- 🖼️ Calculate dimensions to maintain specific aspect ratios
- ⏱️ Convert frame counts to video duration (seconds)
- 🔍 Search the web for gear reviews, photography techniques, and editing tips
