# Practice 07: Home Improvement & DIY Agent

## 📋 Description
This agent acts as a smart home renovation assistant. It can:
- 🎨 Calculate paint required for walls (based on area & coats)
- 📐 Convert area measurements (square meters to square feet)
- 🧱 Estimate tile counts including 10% waste factor
- 🔍 Search the web for DIY guides, material tips, and renovation advice
