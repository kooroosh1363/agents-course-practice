# Practice 10: Sustainability & Eco Agent

## 📋 Description
This agent acts as a smart environmental assistant. It can:
- 🚴 Calculate CO2 emissions saved by walking/cycling vs driving
-  Estimate water savings from reducing shower time
-  Calculate how many trees are needed to offset annual CO2 emissions
- 🔍 Search the web for eco-friendly tips, sustainable practices, and green living advice
