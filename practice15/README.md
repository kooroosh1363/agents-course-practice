# Practice 15: Automotive & Car Enthusiast Agent

## 📋 Description
This agent acts as a smart assistant for car owners and enthusiasts. It can:
- 🔌 Convert engine power from Horsepower (HP) to Kilowatts (kW)
-  Calculate maximum driving range based on tank size & consumption
- 💰 Calculate fuel cost per kilometer for budgeting
- ️ Calculate power-to-weight ratio (performance metric)
- 🔍 Search the web for car reviews, specifications, and maintenance advice
